1. OBJET

Le fichier COTATIONS transmet chaque jour de bourse, apres la cloture, les cours de
l'ensemble des valeurs negociees sur les places couvertes par le contrat (Euronext Paris,
Amsterdam, Bruxelles, Lisbonne ; XETRA et London SE en option). Il contient une ligne de
detail par valeur et par place.

Le fichier est complet : il n'est pas filtre sur le portefeuille du client. C'est au client
de ne retenir que les valeurs qu'il suit.


2. TRANSFERT

Mode        : CFT (Cross File Transfer), partenaire FININFO_COT, flux push vers le client.
Horaire     : mise a disposition entre 18h00 et 18h15 (heure de Paris) les jours de bourse
              Euronext. Pas de fichier les jours de fermeture de la place. En cas d'incident,
              le fichier peut etre redepose sous le meme nom (le client doit accepter un
              ecrasement).
Nommage     : COT_AAAAMMJJ.txt  (AAAAMMJJ = date de bourse, ex. COT_20090615.txt)
Encodage    : ISO-8859-1 (Latin-1). Les libelles de l'enregistrement d'entete peuvent contenir
              des caracteres accentues. Les enregistrements de detail sont en ASCII 7 bits.
Fin de ligne: CR LF (0x0D 0x0A). [SIGEP : lecture par readLine, LF seul accepte aussi]
Taille      : environ 6 000 lignes / 650 Ko par jour.

[BAS : depot dans /appli/sigep/fininfo/entree sur srv-sigep-ref-01, archive dans
 /appli/sigep/fininfo/archive apres integration sans rejet. Import a 18h30, rattrapage 19h30.]
